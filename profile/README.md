## Welcome to RitualDev Lab

**RitualDev** is an independent software studio and research lab. We engineer local-first developer infrastructure, air-gapped AI agent runtime defense, kernel sandboxing, database wire proxies, and production Android applications built with privacy as a mathematical guarantee rather than a marketing slogan.

## Offline-First Android Applications Suite

RitualDev publishes privacy-respecting Android native utilities on the [Google Play Store](https://play.google.com/store/apps/dev?id=8219514430143740943):

- **[All-in-One Calculator](https://ritualdev.in/apps/all-in-one-calculator)**: Over **170+ precision offline tools** covering algebra, finance, unit conversions, geometry, health metrics, and electrical engineering. Zero background tracking, zero data sales.
- **[CyberHub](https://ritualdev.in/apps/cyberhub)**: Essential mobile networking and security toolkit for diagnostics, IP lookups, and port verification.
- **[LifeOS](https://ritualdev.in/apps)**: Minimalist productivity and offline habit ecosystem.
